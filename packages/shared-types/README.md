# @zk-kyc/shared-types

Single source of truth for all credential, proof, and schema types in the ZK-KYC system.

Imported by every package — `apps/wallet`, `apps/mock-issuer`, `packages/zk-core`, and `packages/verifier-sdk`. No type definitions are duplicated elsewhere.

## Types

- `SignedCredential` — Credential returned by issuer (hashes only, no raw values)
- `ProofRequest` — Proof request from verifier (encoded in QR code)
- `ProofPayload` — Proof generated by wallet (sent to verifier relay)
- `FieldProof` — Individual field proof (Merkle inclusion + predicate)
- `MerkleProof` — Merkle inclusion proof for a single leaf
- `PredicateWitness` — Commitment + witness for threshold predicates
- `VerificationResult` — Result of `verifyProof()` with per-check breakdown
- `CredentialStatusEnum` — Active / Revoked / Suspended

## Build

```bash
pnpm --filter @zk-kyc/shared-types build
```
